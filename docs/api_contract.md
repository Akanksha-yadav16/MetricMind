# MetricMind API Contract

## Base URL

```
http://127.0.0.1:8000
```

---

## GET /

### Description
Returns a message indicating that the API is running.

### Response

```json
{
  "message": "MetricMind API is running!"
}
```

---

## GET /total-orders

### Description
Returns the total number of orders.

### Response

```json
{
  "total_orders": 10
}
```

---

## GET /total-customers

### Description
Returns the total number of customers.

### Response

```json
{
  "total_customers": 10
}
```

---

## GET /total-revenue

### Description
Returns the total revenue.

### Response

```json
{
  "total_revenue": 168200.0
}
```

---

## GET /average-order-value

### Description
Returns the average order value.

### Response

```json
{
  "average_order_value": 16820.0
}
```

---

## GET /top-selling-product

### Description
Returns the top-selling product.

### Response

```json
{
  "product": "Headphones",
  "quantity_sold": 2
}
```

---

## GET /top-customer

### Description
Returns the customer with the highest spending.

### Response

```json
{
  "customer": "John Doe",
  "total_spent": 77500.0
}
```

---

## GET /revenue-by-product

### Description
Returns the revenue generated by each product.

### Response

```json
[
  {
    "product": "Laptop",
    "revenue": 75000.0
  },
  {
    "product": "Smartphone",
    "revenue": 45000.0
  }
]
```
