# MetricMind

## Project Overview
MetricMind is a Data Lakehouse project built using Snowflake. The project stores customer, product, order, and order item data for business analytics and reporting.

## Technologies Used
- Snowflake
- SQL
- Git
- GitHub

## Project Structure
```
MetricMind/
├── README.md
├── data/
│   ├── customers.csv
│   ├── products.csv
│   ├── orders.csv
│   └── order_items.csv
└── sql/
    ├── database_setup.sql
    ├── load_data.sql
    └── verify_data.sql
```

## Database Tables
- CUSTOMERS
- ORDERS
- PRODUCTS
- ORDER_ITEMS
